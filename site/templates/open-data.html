데이터 제공 · 임베드

{{siteName}}이(가) 수집한 상품권 핫딜 데이터를 JSON 피드와 임베드 위젯으로 제공합니다. 시세 사이트, 커뮤니티, 블로그 어디서든 가져다 쓸 수 있습니다.

이용 조건

  • 출처 표기: 데이터를 표시하는 화면에 "출처: {{siteName}}"과 이 사이트로의 링크를 함께 표시합니다. 응답의 source 필드를 그대로 쓰면 됩니다.
  • 재판매 금지: 데이터 자체를 유료로 판매하거나 유료 API로 재제공할 수 없습니다. 자신의 서비스 안에서 표시하는 것은 자유입니다.
  • 호출 간격: 피드는 15분 캐시됩니다. 같은 엔드포인트를 15분에 1회 이상 호출할 필요가 없습니다.
  • 원문 존중: 딜의 원문 커뮤니티 글 링크(deal_url)를 제거하지 않습니다.
  • 제외 요청으로 삭제된 딜은 피드에서도 사라집니다. 캐시한 데이터도 24시간 내 갱신해 주세요.

JSON 피드

경로설명
/api/deals.json진행 중 딜. ?limit=50&status=active|live|ending|ended&brand=슬러그&category=gift&sort=score|recent|discount
/api/brands.json브랜드 슬러그 목록
/api/brands/{slug}.json브랜드별 딜
/api/weekly/{YYYY-Www}.json주차별 딜(브랜드 묶음)
/api/deals/{id}.json딜 상세(출처 글, 일별 가격, 과거 반복)
/api/status.json마지막 갱신 시각, 갱신 지연 여부
